ミニ掲示板

概要
フロントエンド(HTML)、バックエンド(Java)、DBが連携したWebアプリの作成に挑戦のため作成してました。

主な機能
ユーザー登録機能：ユーザーを登録できる。
ログイン機能：ログイン処理を行う。
メッセージの投稿機能：投稿内容を保存できる。
ログアウト機能：セッション情報を破棄し、トップページに戻る。
投稿一覧表示機能：投稿情報一覧を表示する。
